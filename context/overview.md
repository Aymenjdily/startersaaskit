# NextSaaS Kit — Project Overview

## Vision
The open-source, fully-tested SaaS starter template that developers choose when they want to ship fast without sacrificing quality.

## Mission
Eliminate the 2–4 weeks of boilerplate work (auth, billing, testing, CI) that every SaaS developer repeats, and replace it with a 60-second clone + customize workflow.

## Core Values
- Tested by default — Every feature has unit, component, and E2E tests
- AI-optimized — Structured so AI coding assistants understand the codebase instantly
- Modular — Swap auth, DB, billing, and UI libraries without rewriting logic
- Transparent — Built in public, documented thoroughly, community-driven using this overview
